
# Real Estate Price Predictor 🏡

This is a Streamlit-based app that predicts real estate prices based on area (sqft).

## How to Run

### Local Setup

1. Install dependencies:
```bash
pip install -r requirements.txt
```

2. Run the app:
```bash
streamlit run app/main.py
```

### Streamlit Cloud

- Upload this repo to GitHub.
- Connect it to Streamlit Cloud and set `app/main.py` as the entry point.

## Model

- Linear Regression trained on real estate dataset.
